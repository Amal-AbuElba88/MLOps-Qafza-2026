# Monitoring alerts

- Alert when the five-minute API error rate exceeds 5%.
- Alert when p95 request latency exceeds 1 second for 10 minutes.
- Alert when prediction-probability PSI reaches 0.20 after at least 20 samples.
- Investigate if the late-prediction rate changes by more than 20 percentage points from the training baseline.
- Retain prediction records until actual delivery outcomes can be joined and evaluated.
